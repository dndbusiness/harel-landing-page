# הר-אל פתרונות מימון חכמים — אתר החברה

אתר סטטי בעברית (RTL), רספונסיבי, ללא תלות בשרת. מתארח ב-GitHub Pages.

## מבנה

```
index.html          דף הבית
mashkanta.html      משכנתאות
rechev.html         הלוואות רכב
asakim.html         מימון לעסקים
kol-matara.html     הלוואות לכל מטרה
about.html          אודות והצוות
contact.html        צור קשר
404.html            דף שגיאה
robots.txt, sitemap.xml
assets/             style.css, site.js, לוגו, תמונות, favicon
webinar/            דף הנחיתה המקורי של הוובינר (נשמר כפי שהיה)
build/              המחולל שכותב את קבצי ה-HTML
design/             קנבס העיצוב שממנו נבנה האתר
```

## עריכה

קבצי ה-HTML **נוצרים אוטומטית** — אל תערכו אותם ישירות, כי הבנייה הבאה תדרוס אתכם.
התוכן יושב ב-`build/pages.py`, המעטפת המשותפת (כותרת, פוטר, רכיבים) ב-`build/_site.py`,
והעיצוב ב-`assets/style.css`. אחרי שינוי:

```bash
python3 build/build_site.py     # כותב מחדש את כל העמודים
python3 build/check_site.py     # קישורים שבורים, גלישה, תפריט וטופס (דורש playwright)
```

`assets/style.css` ו-`assets/site.js` נכתבים ידנית ואינם נוצרים אוטומטית.

## מה מחובר

- **טופסי הלידים** שולחים ל-Google Apps Script של החברה — אותו יעד של דף הנחיתה הקיים.
  הקבוע נמצא בראש `assets/site.js`.
- **כפתורי הוואטסאפ** מפנים לקבוצת הוואטסאפ של הר-אל. כדי להפנות לשיחה אישית במקום,
  מלאו את `WHATSAPP_NUMBER` בראש `assets/site.js` (למשל `972501234567`).

## מה עוד צריך למלא

כל טקסט מודגש בזהב עם קו מקווקו באתר הוא נתון שחסר לנו:

| נתון | איפה |
|---|---|
| טלפון ואימייל | כותרת עליונה, פוטר, `contact.html` |
| שם החברה הרשומה, ח.פ., מספר רישיון | הגילוי הנאות בפוטר, `about.html`, `contact.html` |
| מספרי לקוחות, גופים מממנים, היקף אשראי, שנת הקמה | פסי הנתונים, `about.html` |
| טווחי סכומים, תקופות וריביות | `rechev.html`, `kol-matara.html` |
| שעות פעילות וזמן מענה | `contact.html` |

בנוסף: שלוש עדויות הלקוחות בדף הבית מסומנות **"טקסט לדוגמה"** — להחליף בעדויות
אמיתיות שאושרו לפרסום, או להסיר את הסקשן.

**חשוב:** האתר מציג את הר-אל כבעלת רישיון למתן שירותי אשראי מרשות שוק ההון.
יש לאמת שזה נכון ומה קטגוריית הרישיון לפני שהאתר נחשף לציבור.

## דומיין

הכתובת מוגדרת בקבוע אחד — `SITE_URL` בראש `build/_site.py`. הוא מזין את
ה-canonical, את תגיות ה-Open Graph ואת ה-sitemap. כשמחברים דומיין משלכם:
משנים אותו, מריצים `python3 build/build_site.py`, ומוסיפים קובץ `CNAME`.
